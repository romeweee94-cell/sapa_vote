เว็บแอประบบโหวตรูปภาพ ธีมสีเหลือง-แดง ทันสมัย พร้อมระบบสมัครสมาชิก (1 บัญชีต่อ 1 อุปกรณ์)

## 🚀 ขั้นตอนอัปโหลดขึ้น GitHub

## 🌐 ขั้นตอน Deploy บน Vercel

1. ไปที่ [vercel.com](https://vercel.com) → **Add New → Project**
2. เลือก repository ที่เพิ่งอัปโหลดขึ้น GitHub → กด **Import**
3. หน้า Configure Project ปล่อยค่าเริ่มต้นทั้งหมด (Vercel จะตรวจพบว่าเป็น Next.js เอง)
   แล้วกด **Deploy** (รอบแรก deploy อาจจะยังใช้งานฐานข้อมูล/อัปโหลดรูปไม่ได้ เพราะยังไม่มี
   ฐานข้อมูล ให้ทำขั้นตอนถัดไปก่อน)
4. หลัง deploy เสร็จ เข้าไปที่โปรเจกต์ → แท็บ **Storage**
5. กด **Create Database → Postgres** → ตั้งชื่อ → **Create** → ระบบจะถามให้เชื่อมกับ
   โปรเจกต์นี้ ให้กด **Connect** (จะได้ค่า `POSTGRES_URL` ฯลฯ เข้าโปรเจกต์อัตโนมัติ)
6. กลับไปที่แท็บ **Storage** อีกครั้ง → กด **Create Database → Blob** → ตั้งชื่อ → **Create**
   → กด **Connect** เพื่อเชื่อมกับโปรเจกต์นี้เช่นกัน (จะได้ `BLOB_READ_WRITE_TOKEN`
   เข้าโปรเจกต์อัตโนมัติ)
7. ไปที่แท็บ **Deployments** → กดปุ่ม **... → Redeploy** ที่ deployment ล่าสุด
   (ต้อง redeploy 1 ครั้งเพื่อให้ค่าตัวแปรใหม่มีผล)
8. เสร็จแล้ว! เข้าเว็บผ่านโดเมนที่ Vercel ให้มา ระบบจะสร้างตารางฐานข้อมูลที่จำเป็นให้เอง
   โดยอัตโนมัติในการเรียกใช้งานครั้งแรก (ไม่ต้องรันคำสั่ง SQL เอง)

**สรุปแบบย่อ:** อัปโหลดขึ้น GitHub → Import เข้า Vercel → กด Create Database (Postgres)
1 ครั้ง → กด Create Database (Blob) 1 ครั้ง → กด Redeploy 1 ครั้ง → ใช้งานได้เลย

### วิธีเปลี่ยนรหัสผ่านแอดมิน / ความปลอดภัยเพิ่มเติม (ไม่บังคับ)
ไปที่โปรเจกต์บน Vercel → **Settings → Environment Variables** → เพิ่มตัวแปร:
- `ADMIN_PASSWORD` = รหัสผ่านใหม่ที่ต้องการ
- `SESSION_SECRET` = ข้อความสุ่มยาว ๆ (ใช้เซ็นชื่อ cookie ให้ปลอดภัยขึ้น)

แล้วกด Redeploy อีกครั้งให้ค่ามีผล

## 🔒 ข้อจำกัดของระบบ "1 อุปกรณ์ต่อ 1 บัญชี" ที่ควรทราบ

ระบบผูกบัญชีกับอุปกรณ์ผ่าน cookie ซึ่งเป็นวิธีมาตรฐานที่เว็บโหวตทั่วไปใช้ แต่มีข้อจำกัด
ตามธรรมชาติของเว็บเบราว์เซอร์คือ:
- ถ้าผู้ใช้ล้าง cookie / ใช้ Incognito / เปลี่ยนเบราว์เซอร์ ระบบจะมองว่าเป็นอุปกรณ์ใหม่
- ไม่มีเทคโนโลยีเว็บใดที่ระบุ "อุปกรณ์จริง" ได้ 100% หากไม่ติดตั้งแอปเฉพาะ (native app)

หากต้องการความเข้มงวดสูงขึ้น แอดมินสามารถตรวจสอบรายชื่อผู้สมัคร + รหัสอุปกรณ์ในหน้า
"ผู้สมัคร" เพื่อตรวจสอบความผิดปกติ (เช่น ชื่อคล้ายกันสมัครพร้อมกันหลายบัญชี) และลบบัญชี
ที่ไม่ต้องการได้ทันที

## 🗂️ โครงสร้างไฟล์หลัก

```
app/
  page.tsx              → หน้าโหวตสำหรับผู้ใช้ทั่วไป
  admin/page.tsx         → แผงควบคุมแอดมิน
  api/                    → API ทั้งหมด (สมัคร/ล็อกอิน/โหวต/แอดมิน ฯลฯ)
lib/
  db.ts                   → เชื่อมต่อฐานข้อมูล + สร้างตารางอัตโนมัติ
  auth.ts                 → จัดการ cookie ผู้ใช้/แอดมิน
  session.ts              → เซ็นและตรวจสอบ token
  device.ts               → จัดการ device id cookie
```
